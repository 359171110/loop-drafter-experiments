# Capture execution benchmark

2026-11-09，NVIDIA H20；FP32 Ouro 四轮、SDPA、BF16 特征、原 4/2/1 等长批次、greedy EOS/512。

同一 GPU 上逐组成对测量原实现和 `--backend graph`。耗时包含预填充、图构建、解码和特征回传，写盘耗时由生产进程单独记录。

| 输入 tokens | 批大小 | 原实现 / 秒 | Graph / 秒 | 加速比 |
|---:|---:|---:|---:|---:|
| 100 | 4 | 24.12 | 17.85 | 1.35× |
| 975 | 2 | 29.21 | 26.04 | 1.12× |
| 1886 | 1 | 34.46 | 31.92 | 1.08× |

这 7 条提示覆盖提前 EOS 与输出上限；所有 token、输出长度和保存的 BF16 特征逐元素一致。CPU 测试另覆盖混合 EOS 时刻、缓存前缀和原位覆盖。这里的加速比针对上述三组采集调用；整套采集的吞吐需根据生产状态累计统计。

实现预分配 KV 与特征存储，仅投影预填充最后一个位置的 logits，使用 CUDA Graph 重放 decode，并每 128 个位置调整注意力读取范围。冻结提示、四轮计算、精度、批次上限、训练预算和评测协议保持一致。已有轨迹直接恢复，新增轨迹记录 `capture_backend`。

原始测量见 [capture-benchmark.json](capture-benchmark.json)。
